# At-Towfiiq MasjidBox prayer times

Source: https://masjidbox.com/prayer-times/masjid-at-towfiiq

The public prayer section is an iframe of the named MasjidBox listing for **Masjid At-Towfiiq, 24 Punch Street, Bolton**. The website no longer loads the earlier AlAdhan-based calculation script, so inaccurate generic prayer beginnings are not shown as the mosque timetable. Iqamah and Jumu'ah are maintained by MasjidBox, not derived from another mosque.

A visible direct link remains available if MasjidBox restricts iframe display. We have not independently verified the frame can render in production.

For a more compact Al-Hidaya-style numeric strip, an authorised At-Towfiiq MasjidBox manager can generate a **Prayer times small** widget under Dashboard → Widgets, enable Athan & Iqamah and Jumuah, and share its unique embed snippet. The widget ID is site-specific, so it must not be guessed or reused from another mosque.

MasjidBox documentation:
https://support.masjidbox.com/add-the-small-prayer-times-website-widget-pltke
https://support.masjidbox.com/does-masjidbox-have-a-public-api-for-prayer-times-sfnfd

The former `prayer-times.js`, `prayer-times.css` and `data/prayer-config.json` are retained temporarily as unused historical files pending cleanup. Neither script nor reference stylesheet is loaded on the public page.
